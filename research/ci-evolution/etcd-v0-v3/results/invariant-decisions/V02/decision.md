**Decision: targeted maintenance is required.** Retain the old suite’s consensus, configuration provenance, joint-recovery and quorum requirements. Change the documented learner-vote and RawNode `Ready` contracts, migrate observations, repair specific old oracle defects, and add checks where the old suite is too weak. This is an independent static assessment, not a passing verdict on the implementation.

Only `/workspace` inputs were used. No tests or TLC were executed, no other agents or external sources were consulted, and no source/spec files were changed. [decision.json](decision.json) contains the individual decisions, source locations, precise predicates, concrete witnesses, coverage explanations and unresolved obligations. Witness outcomes are predictions for later validation.

Keep `TransferDecisionEligibility`, `RequestCorrelatedConfigurationEffects` and `ProposalConfigurationDecisions`: permitting learner votes does not permit learner leadership transfer or change configuration admission/application. Their existing observers check target decisions, committed entry/request correspondence, and pending-change rewriting for both legacy and V2 entries. Add observation of the refactored configuration switch’s commit recalculation, replication and transfer-abort effects; configuration equality alone does not establish them.

Keep the unaffected safety controls, including `ElectionSafety`, `LogMatching`, `LeaderCompleteness`, `CommittedHistory`, `AppliedAgreement`, durable vote/promise backing, replication evidence, quota bounds, read basis/application/correlation, types and log structure. Each retained entry has a concrete negative control. Identical retained predicates cannot honestly have different truth values; the JSON distinguishes these controls from disagreement witnesses. No whole correctness property is removed. Update-module aliases continue to refer to their base predicates.

Existing coverage is substantive but limited. `QuorumAccounting` records the configuration and acknowledgements at wins/commits and intersects them with each voter half. `ReadBasis` checks both majorities in the recorded confirmation configuration. These already exclude nonvoter contributions, but they do not detect refusal to elect with a sufficient quorum, unnecessary undercommit, or incorrect CheckQuorum decisions. Additional decision/exactness checks address those gaps.

**Defects must remain visible.** Static inspection identifies:

- Snapshot admission still scans only `Voters` and `Learners`, excluding outgoing-only members.
- `numOfPendingConf` still ignores V2 entries. Retain the stronger campaign requirement.
- `TestLearnerCanVote` uses a faulty conjunction that can accept rejection; the property must require the exact successful response.
- `Node.Tick` reads mutable leader state outside its event loop. `SetLogger` locks writers, but construction reads the global logger without that lock; the latter API’s concurrency scope remains unresolved.
- Successful automatic leave appends do not advance `pendingConfIndex`; repeated exits before application are a suspected pre-existing defect requiring a paginated witness.

The old joint-recovery canary detects a **configuration mismatch**, so correct recovery will stop triggering it. Change it to observe a recovery event independently of correctness; keep recovery equality as a separate invariant.

Validation remains open. Migrate the new reference actions as well as observers, then execute the witnesses. Exercise both Node and RawNode, joint demotions, both AutoLeave values, preview/Advance interleavings, and 7/8-element helper boundaries. Existing configurations omit some relevant properties/workloads. Existing election liveness assumes common configurations and stable services, so it does not establish recovery when a promoted node still believes it is a learner and the old leader has failed. Malformed ConfState handling, automatic-exit liveness/repetition, removed-leader policy, and source-level representation/concurrency checks remain explicit obligations; no completeness claim follows from retaining properties.
