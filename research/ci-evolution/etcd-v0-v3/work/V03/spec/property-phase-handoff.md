# Preserved properties and evidence for the next phase

The actual original V02 operators and configurations are in `assets/v02`. Predicate definitions in the evolved suite are preserved, including TypeOK, ProposalContract, AutoLeaveAdvance, ReadyOwnership, transfer/vote/campaign contracts, and every original invariant/property list. No global property-checking campaign was run. The finite LocalActions `Emit` invariant only serializes candidates/transitions; it is not a protocol correctness check.

`history.autoLeaveChecks.eligible` retains its exact old definition: AutoLeave, cursor >= pending, Leader. It still omits both cursor > 0 and the new oldApplied < pending condition. It has NOT been silently repurposed. New observation fields `oldApplied`, `cursor`, `pendingBefore`, `crossingEligible`, `quotaBefore`, `committedWeight`, and `quotaAfter` coexist with that legacy value. AutoLeaveAdvance therefore remains the old obligation, even on source-permitted V03 stutters. A later phase must decide whether/how to revise it using state-space evidence, not this local implementation result alone.

`ProposalObservation` adds the complete prior configuration. All original fields and their meanings remain. ProposalContract still specifies the old pending-only rewrite and old quota admission; it is not updated to V03 phase or zero-size behavior. The new field enables the next phase to analyze that distinction. Helpers used by property definitions (ConfigAfter, ConfigCandidate, IsLeave, EntersJoint, quorum and vote contracts) retain their meaning. Progress lifecycle helpers are behavior, not new normative requirements.

Representation changes are separate: nil Data is represented by weight=0 and encoded=6 in concrete adapters; automatic leave now uses those existing Entry fields, and Trace binds its size to TraceEmptyEncoded. Next=0 is admitted by the structural INPUT audit because V03 initProgress produces it. TypeOK was not edited. Bootstrap concrete sizes are 6 payload/14 encoded bytes, supplied by adapter overrides rather than changing compact MC abstractions.

The final JSONL records retain actual pre-state, actual mapped input (including captured Ready), whole declared post-state, status, raw Go panic/error/messages and TLC fatal/decision. `model_witnesses` exports autoLeaveChecks and proposal observation. `out/evidence/disagreements.json` links baseline/repaired/V02 results for every baseline disagreement. Inputs, initial failing adapter outputs, syntax failures, repaired reruns, and semantic deltas are retained. They are local injected action evidence, not proofs of distributed reachability or real bugs.

Preserved implementation behaviors include: empty explicit/implicit V2 proposals accepted in joint state then panicking on application; removed/demoted leaders retaining role (and early-return transfer state); pending bookkeeping surviving a later quota drop; nonempty configuration changes subject to quota despite the broad source comment; V2 entries still omitted by the Hup pending-config scan; outgoing-only live snapshot rejection; zero-Next and empty-refill behavior. These observations must not by themselves dictate intended property changes.

A further pre-existing repair separates the append return from the inherited `decision` observation. A rejected proposal between Ready and Advance leaves `decision=DropQuota`, even if the automatic append succeeds. `AdvanceCore` now consults `AppendQuotaExceeded` for that call; the observation and old predicates are unchanged. The added `appended` witness explicitly records whether the log grew. V02 quota-14 and V03 quota-14/17 failures and repairs are saved.

The injected configuration-broadcast panic case also preserves partial effects: source execution stops before transfer cancellation. `ApplyConfCore` now returns its fatal state before aborting transfer. The inherited model continued after fatal; this is a pre-existing local model repair, not a claimed reachable Raft bug.
