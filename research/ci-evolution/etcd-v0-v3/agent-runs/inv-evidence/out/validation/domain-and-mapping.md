The replay background is the existing adapter's local record domain: server IDs 1..4, node 1 as the subject, finite typed configuration sets, natural term/index/pending/quota fields, contiguous log entries, fixed 10/1 election/heartbeat ticks, cap 16, two inflight slots, and explicit message/Ready inputs. Logs, quota and membership are injected; TypeOK-shaped local structure is not proof of global reachability or simultaneous satisfaction of the old invariant suite. Forbidden old proposal/auto-leave/transfer behavior is retained in the domain. No restriction to V03 reachable states is used.

V01/V02/V03 share the abstract configuration record (incoming voters, outgoing voters, learners, staged learners, AutoLeave). V01 protobuf Nodes/NodesJoint map to V02/V03 Voters/VotersOutgoing; the remaining fields map directly. Messages are bags, reads/entries are ordered sequences, contexts use the supplied finite encoding. Term/index/id/target/changes/transition/payload weight/encoded size are all retained. Canonical automatic leave changes from V01/V02 payload 2 and encoded size 10 to V03 payload 0 and encoded size 6 in the concrete replay configuration. The symbolic spec keeps its supplied encoding abstraction.

V00's native configuration has only voters and learners. The lossless embedding sets outgoing/staged empty and AutoLeave false. Joint configurations, V2 entries and automatic-leave states have no native V00 API/state representation. Such old code results are not-representable/unsupported, not rejected. The explicit union-voter projection in the quorum property witness is lossy and diagnostic: a native old flat Step commits 2 with acknowledgments {1,2}; the full new joint {1,2}/{2,3} Step stays at 1. It does not claim that V00 executed a joint transition. Ack comparisons lift the original V00 predicate to its existing before/after/cursor/snapshot observation fields; V2 appended entries extend the observation background, not the V00 state type.

Standalone witness records are emitted from actual mapped action observations, then serialized back into TLA records with set/sequence/bag types restored. The explicit bootstrap/joint/leave commit records are constructed contract tests; separate real MsgAppResp replays cover both a correct predecessor configuration and a deliberately premature final configuration. Nonempty original commitUses, Ready and Advance histories are exported. Original QualityEvent/VoteObservation/CampaignObservation/ProposalObservation execute on real pre/post/input states. Audit adds missing raw facts; no helper-only empty quality/history check counts as validation. Configuration transfer observations reconstruct the real ApplyConfCore callback pre/post transfer and configuration fields, without fabricating committed-entry/request provenance for EffectContract.

Constructed mutations change one obligation near a real observation: extra suffix, noncanonical leave, prefix/cursor/snapshot damage, omitted pending update, illegal positive-payload acceptance, stale-log vote grant, wrong Ready quota, later read loss, and reversed demotion cancellation. These are property tests, not current implementation bugs. Background records intentionally include forbidden transitions.

The existing terminal-panic boundary remains: internal buffer ordering after panic may be unobservable. Pre-state, inputs and ordinary messages are never suppressed. This selected replay set contains no terminal panic; the framework's documented boundary is retained, not newly certified.
