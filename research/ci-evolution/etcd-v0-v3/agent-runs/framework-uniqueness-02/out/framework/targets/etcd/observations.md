# Observation map and domain

Current versions: supplied V02 and V03. IDs 1–4, local ID 1, ticks 10/1, inflight capacity 2, message/Ready cap 1024, uncommitted cap 16, safe reads. The source-derived descriptors preserve all 239 prior local cases and add phase/quota/progress/auto-leave/caller boundaries. TLC builds finite inputs in ModelDomains and calls the actual original/evolved operators through LocalActions; it never computes expected successors in Python.

The normal projection includes term/vote/role/leader/configuration, applied/committed/pending cursors, quota and transfer, visible/stable/unstable log, snapshot, full progress, messages, votes, read queue/acks and results, prevHS/prevSS, tick counters, CheckQuorum/PreVote, and MemoryStorage. Constructor/restart pre-observation instead records actual Storage and constructor options. Bootstrap pre-observation is an actual newly constructed empty RawNode; its peer list is carried in input.snapshot.config.voters and passed in that sequence order to Bootstrap. The model binds the same list in an original base instance.

Entry weight is actual len(Data); encoded is actual protobuf Entry.Size(). Empty nonnil normal data is encoded=8; nil normal or V2 data is encoded=6. Legacy payloads are 6 bytes; ordinarily marshaled empty V2 is 2 bytes, unlike V03's nil auto-leave. `Encoded=6,Weight=0` directs the Go adapter to use nil Data; all measured inputs are compared with the model mapping. Bootstrap payload/encoded overrides are 6/14. Compact MC weights remain abstract. TypeOK and other correctness predicates are unchanged.

Snapshot installation, entry append and HardState installation before Advance are explicit caller persistence mappings. Initial log suffixes may already be present in MemoryStorage but unacknowledged by raft; prepared newly captured snapshots/entries are installed before Advance. Captured Ready is an input observation and `batchAfter` is an ownership observation of that same Go batch, not an API return. Intervening operations run real Step calls (or Node channels), including a quota rejection, before Advance.

Node cases run actual node.run with no tick producer or concurrent external caller. Status exchanges serve as execution barriers. Ready-empty cases observe a bounded absent channel delivery after HasReady=false. Callback cases use Node.ApplyConfChange then public Node.Propose with a 30 ms context deadline. Removed members block the proposal channel; demoted leaders still in progress may admit it. Disabled status is an explicit caller prerequisite, not a source rejection, successful transition, or untested case. Callback composites retain changed configuration state even if the later proposal is disabled. An asynchronous intervening Node proposal need not return a core drop error, but its resulting state and subsequent Advance are compared.

Status is separate from state: ok, dropped, panic, disabled; adapter failures/unsupported are separate envelope statuses. Panic text is raw evidence, not normalized equality. TLC `decision` is an inherited ghost of the last core decision; it must not be used as a later append's return value. The repaired model shares the current per-call quota condition between AppendEntry and AdvanceCore. Legacy autoLeaveChecks.eligible retains its old predicate; extra fields describe the new crossing and append effect. Those raw model witnesses are exported outside the comparison observation.

Configurations, progress, votes, ack sets and messages are unordered; message multiplicity remains exact. Logs, changes, read queues/results and inflights remain ordered. Campaign recipient ordering is omitted by the multiset abstraction even though V03 sorts it. Numeric read contexts and explicit forced-transfer context are modeled. Arbitrary protobuf/context bytes, unknown transitions and corrupted tracker maps are outside the normal descriptor domain.

Structural input auditing checks membership shape, log indices, cursor/quota backing and progress IDs. Next=0 is allowed because V03 initProgress emits it; no Next>Match protocol invariant is assumed here. The zero-Next fatal/partial-state cases are injected boundaries, including one Match/Next combination without a demonstrated reaching trace. Empty ConfState is used only for construction. Snapshot histories below the visible cut are ghosts. None of these setups establishes distributed reachability.

Full lifecycle behavior is not exhausted: there is no global search, crash/network schedule enumeration, arbitrary pagination, post-restart application replay, disk failure simulation, byte-level malformed input campaign, random-timeout distribution check, broad Node cancellation schedule, or linear Trace NDJSON run. Syntax preflight covers base, MC, Update, and Trace; local TLC runs syntax-check LocalActions/ModelDomains and invoke original actions. Retained safety/liveness predicates are assets for the next phase, not evaluated conformance requirements in this phase.
